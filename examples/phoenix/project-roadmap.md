# Roadmap

## Fase 1 — Preparazione

- backup configurazione attuale
- inventario hardware e software
- verifica compatibilità Eddy NG
- verifica compatibilità Daemon Macro
- piano di ritorno al firmware Sovol

## Fase 2 — Migrazione Mainline

- preparazione microSD
- installazione sistema
- verifica MCU e periferiche
- configurazione base
- reintegrazione Eddy NG
- reintegrazione Daemon Macro
- stampa di prova

## Fase 3 — Piatto R3men

- montaggio meccanico
- installazione SSR Omron
- dissipatore
- verifica terra e cablaggio
- configurazione termistore
- PID bed
- Z offset
- QGL e bed mesh

## Fase 4 — Camera e ASA

- isolamento inferiore del piatto
- coibentazione enclosure
- verifica temperature camera
- profilo ASA
- stampa provini dimensionali

## Fase 5 — Toolhead

- stampa componenti Xenomorph
- verifica Eddy NG
- valutazione toolboard originale
- eventuale EBB36/EBB42
- eventuale CAN bus
